# Scroll film — clean-up config for scripts/prepare-film.sh
# All coordinates are in SOURCE pixels (1920x1080), times in seconds.
# Measured frame by frame from assets/film/source/little-naturals-journey.mp4.
# If you replace the video, re-measure these (see README "Scroll film").
#
# blur <name> <pad> <feather> <t:x0:y0:x1:y1> ...
#   A soft blur patch that follows the text. Each keyframe is the text's
#   bounding box at time t; positions are interpolated between keyframes.
#   The patch is active from the first keyframe to the last. <pad> grows the
#   fully-blurred area past the text; <feather> adds a gradual fade of that
#   many px around it (0 = tight, e.g. next to a face). Every edge also gets
#   the global Gaussian softening below.
#
# focus <t:cx> ...
#   Horizontal centre of the 4:5 mobile crop over time (keeps faces in frame).
#
# logo <x> <y> <w> <h>
#   Box handed to ffmpeg's delogo to remove the generator watermark.
# ==========================================================================

logo 1696 856 88 88

# feather <sigma>: global Gaussian softening (px) applied to every patch edge
feather 9

# 0.00–10.00  soften delogo's streaks where the watermark was (whole film)
blur logo-soften 0 18  0:1700:860:1780:940 10:1700:860:1780:940

# Mobile 4:5 crop: follow the children/people in each scene
focus 0:1100 1.35:1100 1.6:1000 2.3:950 3.0:900 3.3:980 4.5:1000 5.9:1000 6.2:760 6.5:650 7.4:680 7.7:820 8.5:900 9.1:960 10:960
